# Future Assistant

Petit assistant personnel web, simple et rapide.

## Fonctionnalités
- Liste de tâches avec priorités
- Barre de progression
- Notes personnelles
- Sauvegarde locale dans le navigateur
- Interface responsive pour ordinateur et mobile

## Utilisation
Ouvre `index.html` dans un navigateur. Aucune clé API n'est nécessaire.

Projet créé pour servir de base à une future assistante IA plus complète.
